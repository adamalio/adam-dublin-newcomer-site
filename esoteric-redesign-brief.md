# Redesign brief: make it truly beautiful and esoteric

Adam's feedback: the site is still not beautiful/esoteric enough. He has much higher standards. The current site is too generic/dashboard-like. Redesign it into a premium, cinematic, visual-first artifact.

Use references from loaded design systems:
- Runway: cinematic full-bleed imagery, dark editorial sections, text as film-title, visual content dominates, minimal chrome.
- Apple: controlled drama, big whitespace, high polish, hero moments, product-as-sculpture approach.
- Clay: warm human color/details, playful cards, tactile surfaces — use sparingly for warmth.

Required mood:
- Esoteric but not tacky: Dublin as a navigational ritual / constellation / field guide.
- Beautiful, atmospheric, premium, editorial.
- Less app-dashboard, more digital magazine / art-directed relocation talisman.
- Use the new hero asset `dublin-astrolabe-hero.png` heavily.

Hard requirements:
1. Keep it static: index.html, styles.css, app.js only, plus image assets.
2. Keep all useful content and source links, but reduce visible prose. Use microcopy, cards, tables, diagrams, and visual systems.
3. New hero must feel like a luxury landing page: full-bleed image, dark overlay, huge elegant headline, short subtitle.
4. Add at least 5 visual modules:
   - ritual path / first 7 days timeline
   - social constellation network
   - Dublin area compass / route map
   - contact velocity chart
   - football ladder / progression
   - source card wall
5. Use CSS art/SVG-like divs when useful. Avoid blocks of paragraphs.
6. Make mobile responsive and visually good.
7. No Google logo misuse. Can say Google / Grand Canal Dock in text.
8. Verify JS syntax.

Visual design direction:
- Deep black / midnight / dark green / gold / fog / ivory.
- Typography: large serif or editorial display for headings if using Google Fonts, paired with Inter/DM Sans. Import fonts in HTML.
- Use glass panels, fine lines, orbital rings, constellations, map paths, glowing nodes, large imagery.
- Tables should look designed, not default.
- Text density must be low.

Self-review before final:
- Would Adam call this “beautiful” rather than “dashboard”?
- Is the first viewport visually impressive?
- Does it use imagery and diagrams much more than text?
- Is it still practical/useful?
